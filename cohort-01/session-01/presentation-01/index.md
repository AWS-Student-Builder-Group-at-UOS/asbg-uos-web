> 눌러 보는 공부에서, 함께 만들고 운영하는 공부로

1기 첫 세션의 킥오프를 맡았습니다. ASBG UOS가 어떤 모임이고 한 학기를 어떻게 보낼지 소개하는 자리였는데, 그 바탕에 깔린 질문은 하나였습니다. AWS를 왜 혼자가 아니라 같이 배우는가. 이 글은 그 질문에 대한 제 답입니다.

## 01. 자격증 공부에서 커뮤니티까지

저는 작년 2학기에 클라우드에 관심이 생겨 자격증 공부부터 시작했습니다. 공부하다 보니 서버리스 아키텍처가 재미있어서 AWS 한국사용자모임 세미나에 나가게 됐고, 그 경험이 학교 안에도 이런 모임을 만들어 보자는 데까지 이어졌습니다. 지금은 9월부터 DevOps 직무 인턴으로 일하면서 쿠버네티스를 공부하고 있습니다.

ASBG는 AWS Student Builder Group의 약자입니다. AWS가 전 세계 대학 단위로 운영하는 학생 커뮤니티 프로그램이고, Learn, Build, Connect 세 단어를 내걸고 있습니다. AWS 서비스가 무엇이고 어떤 상황에서 쓰는지 배우고, 직접 만들어 보면서 각 서비스의 역할을 확인하고, 만든 것을 서로 보여 주면서 진로와 기술 고민을 나눈다는 뜻입니다. 서울시립대에서는 이번 학기에 1기를 시작했습니다.

## 02. 콘솔에서 눌러 보는 것과 서비스를 운영하는 것

AWS를 공부한다고 하면 콘솔에 들어가서 EC2나 S3 같은 서비스를 하나씩 눌러 보는 장면을 먼저 떠올리기 쉽습니다. 그런데 서비스 이름과 화면을 아는 것과 그 서비스로 실제로 무언가를 돌리는 것은 다른 일입니다. 서버를 어디에 두고, 어떻게 배포하고, 트래픽이 몰리면 어떻게 버티고, 비용은 어디서 새는지는 눌러 보는 것만으로는 알 수 없습니다. 설계하고 배포하고 운영하는 데까지 가 봐야 합니다.

그래서 이번 학기 정기 세션은 서비스를 하나씩 배우는 순서가 아니라, 서비스 하나를 조금씩 키워 가는 순서로 짰습니다. 처음에는 VPC 안에 EC2를 두고 ALB와 RDS를 붙여서 3-Tier 구조를 만듭니다. 사용자의 요청을 받는 서버, 트래픽이 몰릴 때 여러 서버로 나눠 주는 로드 밸런서, 애플리케이션과 분리해 관리하는 데이터베이스까지가 한 세트입니다. 그다음에는 서버 없이 돌아가도 되는 부분을 Lambda와 DynamoDB로 떼어 내고, SQS 큐를 사이에 둬서 처리를 뒤로 미루고 서비스끼리 덜 엮이게 만듭니다. 마지막에는 ECR과 ECS로 실행 환경 차이를 줄이고 CodePipeline으로 배포까지 자동화합니다. 학기 끝에는 SAA 문제를 바탕으로 전체를 한 번 되짚습니다.

순서로 보면 네트워크와 서버에서 시작해 서버리스와 이벤트로, 다시 컨테이너와 자동 배포로 옮겨 갑니다. 서버 한 대를 잘 운영하는 문제에서 출발해서 기능 단위로 나누고 자동으로 배포하는 문제로, 점점 실제 서비스 운영에 가까워지는 구조입니다.

## 03. 혼자 하면 막히는 두 지점

혼자 AWS를 시작해 본 사람은 대개 비슷한 데서 멈춥니다. 하나는 비용입니다. 실습하다 켜 둔 리소스가 청구서로 돌아올까 봐 계정을 만드는 단계에서 멈추는 경우가 많습니다. 그래서 세션 과제 실습에 든 비용은 동아리에서 일정 부분 지원합니다. 비용이 무서워서 실습을 안 하는 일은 없게 하자는 취지입니다. 대신 리소스를 켜 놓은 채 방치하면 예상하지 못한 비용이 쌓이니, 실습이 끝나면 리소스를 정리하는 습관을 같이 들입니다.

다른 하나는 혼자서는 내 결과물밖에 볼 수 없다는 점입니다. 같은 과제를 다른 사람은 어떻게 풀었는지, 어디서 막혔고 어떻게 넘겼는지를 보는 것은 커뮤니티에서만 얻을 수 있습니다. 그래서 과제는 무엇을 만들었는지, 왜 그렇게 구성했는지, 어디서 막혔는지, 결과 화면은 어떤지를 정해진 템플릿에 적어 GitHub에 PR로 올리고 서로 리뷰합니다. 이렇게 쌓인 기록은 그대로 각자의 포트폴리오가 됩니다. 직접 와서 같이 듣고 질문하고 다른 사람이 만든 것을 보는 데 커뮤니티 프로그램의 장점이 있다고 생각합니다.

## 04. 자격증은 그다음에

자격증 취득 자체보다는 실습, 개념 이해, 자격증 공부 순서로 연결해 보길 권합니다. EC2 여러 대를 직접 구성하고 앞에 ALB를 붙여 본 다음에 "ALB는 트래픽을 분산한다"는 문장을 다시 읽으면 같은 문장이 다르게 읽힙니다. SAA 같은 자격증 스터디는 코어팀이 정해 주지 않고 하고 싶은 사람이 직접 열고 운영합니다. 코어팀이 모든 활동을 정해 주는 방식이 아니라, 하고 싶은 사람이 직접 모임을 만들 수 있는 구조를 지향합니다.

## 05. 함께 배운다는 것

Connect는 AWS 이야기만 하자는 뜻이 아닙니다. 정기 세션 말고도 진로 고민이나 요즘 AI를 어떻게 쓰는지 나누는 네트워킹 자리, 다른 대학 ASBG와의 교류, 현직자 연사 세션도 함께 만들어 갑니다.

한 학기 동안 서비스 하나를 같이 만들고, 막히는 곳은 같이 풀고, 만든 것을 서로 보여 주면서 갑니다. 다음 세션부터는 각자 콘솔을 열고 시작합니다. 클라우드, 생각보다 재밌습니다.
