# 세션 썸네일 생성 프롬프트

아래 전체를 복사해 AI에게 전달한다. 맨 위 "입력"의 경로만 고쳐 쓴다. 파일을 첨부하는 환경이면 경로 대신 파일을 첨부한다.

---

## 입력

- 디자인 가이드: `template/session-thumbnail/design-guide.html`
- 발표 폴더: `cohort-01/session-01/presentation-01`
- 발표 자료: `cohort-01/session-01/presentation-01/index.md`, `cohort-01/session-01/presentation-01/files/slides.pdf`

## 작업

너는 ASBG UOS 웹사이트의 세션 발표 썸네일을 만든다. 위 디자인 가이드를 기준으로 삼고, 위 발표 자료를 읽어 발표를 대표하는 아이콘을 직접 그린 뒤 SVG 썸네일 한 장을 만든다.

가이드는 HTML 원문으로 읽는다. 렌더링 없이도 필요한 내용이 모두 들어 있다. 템플릿 원문은 `<script id="template">`, 예시 아이콘의 격자 데이터는 `<script id="glyphs">`에 있다. 치수 · 색 · 문자 규칙은 02 ~ 04절, 아이콘 규칙은 05절, 검증 항목은 07절, 템플릿은 08절이다.

## 절차

1. 발표 자료를 읽고 발표를 대표하는 사물 하나를 정한다. 가이드 5.3을 따르고, 같은 세션의 다른 발표 아이콘과 겹치지 않게 한다.
2. 그 사물을 가이드 5.3 규칙대로 16 × 16 격자 문자열로 새로 그린다. 예시 아이콘은 스타일 참고용이며 그중에서 고르지 않는다.
3. 가이드 08 템플릿을 그대로 복사해 다섯 자리를 채운다.
   - `{{COHORT}}` `{{SESSION}}` `{{PRESENTATION}}`: 발표 폴더 이름의 두 자리 번호.
   - `{{KEYWORDS}}`: `index.md`의 `keywords` 세 개를 순서대로 대문자 text 3줄로 쓴다. 크기와 기준선은 가이드 04절 표를 따른다. 가장 긴 키워드의 글자 수로 정한다.
   - `{{ICON}}`: 격자를 rect로 바꾼 목록. 칸 (열 c, 행 r)은 `<rect x="800 + 16c" y="257 + 16r" width="16" height="16"/>`이다.
4. 템플릿의 다른 부분(배경 · 프레임 · 문자 · 글꼴 · 색)은 바꾸지 않는다.
5. 가이드 07 검증 항목을 확인한다. 저장소 안에서 작업한다면 `node template/session-thumbnail/validate.mjs <저장 경로>`를 실행해 통과시킨다.

## 규칙

- 색은 `#0B0F17` `#42B4FF` `#FFFFFF` 세 가지만 쓴다. 아이콘은 `#42B4FF` 단색, 불투명도 1이다.
- 문자는 템플릿의 다섯 줄만 쓴다. 발표 제목 · 발표자 · 한글을 넣지 않는다.
- 키워드는 `index.md` 값을 그대로 쓴다. 바꾸거나 줄이지 않는다. 29자 이상인 키워드가 있으면 썸네일을 만들기 전에 `index.md`의 키워드부터 줄인다.
- 글꼴 · 이미지 · 필터 · 그라디언트를 더하지 않는다.
- 아이콘은 하나다. 글자 · 숫자 · 타사 로고 모양을 아이콘으로 쓰지 않는다.

## 출력

- 발표 폴더의 `img/thumbnail.svg`로 저장한다. 파일에는 SVG 코드만 넣는다.
- `index.md`의 frontmatter에 `thumbnail: img/thumbnail.svg`가 있는지 확인하고, 없으면 추가한다.
- 마지막에 고른 사물과 선택 이유를 한 줄로 보고하고, 아이콘 격자 문자열 16줄을 함께 남긴다.
