01개요

세션 발표 썸네일은 한 가지 틀로 만든다. 배경 · 프레임 · 문자 배치는 고정하고, 발표마다 번호, 키워드 세 줄, 아이콘만 바꾼다. 아이콘은 정해진 목록에서 고르지 않고 발표 내용에 맞춰 그때그때 새로 그린다.

세션 목록 카드(16:10, 폭 약 360px), 발표 상세 페이지 상단, 링크 공유 이미지(1200 × 630 PNG로 변환, 좌우 여백은 배경색)에 쓰인다. 제목 · 발표자 · 키워드 칩은 페이지가 따로 보여준다.

05아이콘

5.1 프레임

오른쪽 위와 왼쪽 아래 모서리를 40px 사선으로 자른 점선 사각형이다. 고정이며 아이콘에 맞춰 바꾸지 않는다.

<path d="M736 214H1080L1120 254V516L1080 556H776L736 516Z" fill="none" stroke="#42B4FF" stroke-width="3" stroke-dasharray="10 14" opacity="0.7" shape-rendering="geometricPrecision"/>

5.2 격자

  • 16행 × 16열, 한 칸 16px, 원점 (800, 257). 전체 256 × 256.
  • 칸 (열 c, 행 r)은 <rect x="800 + 16c" y="257 + 16r" width="16" height="16"/>. 채워진 칸마다 rect 하나를 쓴다. 예: 0행 5열 → <rect x="880" y="257" width="16" height="16"/>
  • rect는 <g id="icon" fill="#42B4FF"> 안에 둔다. 개별 rect에 fill · opacity를 쓰지 않는다.

5.3 그리기

발표마다 아이콘을 새로 그린다. 순서는 다음과 같다.

  1. 발표 자료를 읽고 발표를 대표하는 사물 하나를 정한다. 다루는 서비스나 사물이 있으면 그것을(서버 · 데이터베이스 · 버킷 · 컨테이너 …), 개념이면 관용적인 상징으로 바꾼다(검증 → 체크 표시, 커리어 → 나침반, AI → 칩, 커뮤니티 → 사람들).
  2. 같은 세션의 다른 발표와 겹치지 않는 사물을 고른다.
  3. 16 × 16 격자 문자열로 그린다. 16행, 각 행 16글자, # 채움, . 비움.
  4. 바깥 한 줄(0행 · 15행 · 0열 · 15열)은 비운다. 정사각형이거나 축 대칭이 필요한 형태만 예외로 한다.
  5. 형태는 8행 × 8열 이상을 차지한다. 선은 1칸 이상, 주요 윤곽은 2칸 또는 면 채움으로 한다. 1칸 폭의 빈틈을 길게 두지 않는다.
  6. 수평 · 수직 · 45° 대각선만 쓴다.
  7. 사물 하나만 그린다. 글자 · 숫자 · 화살표 장식 · 타사 로고(AWS 로고 포함)를 넣지 않는다.
  8. 실루엣만으로 알아볼 수 있어야 한다. 카드에서는 약 80px 폭으로 보인다.
  9. 격자를 5.2 규칙대로 rect로 바꾼다. 보고할 때 사물 이름과 격자 문자열을 함께 남긴다.

07검증

  
    
    
  • 루트 <svg>에 viewBox="0 0 1200 750", shape-rendering="crispEdges"가 있고 width · height 속성이 없다.
    • 
    
  • 색은 #0B0F17 · #42B4FF · #FFFFFF 뿐이다. 그라디언트 · 필터 · 이미지 · 외부 참조가 없다.
    • 
    
  • 배경 · 프레임 · 글꼴 스택이 템플릿과 같다.
    • 
    
  • <text>는 5개다. ASBG UOS · COHORT NN, 키워드 3줄, SESSION NN · PRESENTATION NN.
    • 
    
  • 번호 세 개가 폴더 이름과 같다.
    • 
    
  • 키워드 3줄이 index.md의 keywords와 순서대로 같고(대문자), 크기와 기준선이 04절 표와 맞는다.
    • 
    
  • 아이콘은 <g id="icon"> 안의 16 × 16 rect뿐이다. x − 800, y − 257이 16의 배수이고 0 ~ 240 범위이며 중복이 없다.
    • 
    
  • 아이콘이 8행 · 8열 이상을 차지한다.
    • 
    
  • 파일에는 SVG 코드만 있고 30 KB 이하다.
    • 
    
  • 해당 발표의 index.md frontmatter에 thumbnail: img/thumbnail.svg가 있다.
    • 
  

  
자동 검증. 파일이 발표 폴더 안에 있으면 번호와 키워드도 폴더 이름 · index.md와 대조한다. 통과하면 아이콘 격자를 출력한다.
