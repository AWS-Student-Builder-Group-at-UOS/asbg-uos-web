01개요

과제, 프로젝트, 스터디, 기수 전체의 회고를 발표와 같은 구도로 만든다. 왼쪽의 키워드 세 줄, 오른쪽의 점선 프레임과 픽셀 아이콘, 점 격자의 위치와 치수는 발표 템플릿과 같다. 회고는 따뜻한 아이보리 바탕, 검정 글자, 파란 강조색으로 구분한다.

회고끼리는 아이보리 색과 공통 구도, 하단의 RECAP 표기를 고정한다. 기수 번호, 키워드, 관련 활동 표기, 주제 아이콘만 바꾼다. 세션 번호나 과제의 존재를 전제로 하지 않는다. 아래 그림은 템플릿 사용 예시이며 실제 활동 성과를 나타내지 않는다.

요소규칙
캔버스1200 × 750, 16:10. 루트에 viewBox="0 0 1200 750"와 shape-rendering="crispEdges". width · height 속성은 없다.

프레임발표와 같은 점선 팔각 프레임. x 736~1120, y 214~556. stroke 3, dash 10 14, 파란색 불투명도 0.7.

발표와 같은 위치, 크기, 글꼴, 점 격자와 프레임을 유지한다. 별도의 띠, 괘선이나 큰 유형 제목은 추가하지 않는다. 제목과 작성자는 페이지에서 보여주므로 썸네일에 넣지 않는다.

03바뀌는 요소

값은 활동 폴더와 index.md의 frontmatter에서 읽는다. type: retrospective여야 한다. 기수는 cohort-NN, 관련 세션은 선택 필드 session이다. 세션이 없으면 하단에 RECAP만 쓴다. 기수 번호는 상단에 항상 표시한다. 프로젝트나 스터디 회고도 같은 규칙을 쓴다. 제목에서 번호를 추측하거나 가상의 발표 번호를 만들지 않는다.

키워드는 keywords의 세 개를 순서대로 대문자로 쓴다. 영어, 숫자, ASCII 문장부호를 사용한다. 글자 크기와 기준선은 가장 긴 키워드로 정하고, 세 줄의 크기는 같다. SVG 안에서 &, <, >는 엔티티로 바꾼다.

가장 긴 키워드크기기준선 y
18자 이하56318 · 392 · 466
19 ~ 23자44332 · 392 · 452
24 ~ 28자36342 · 392 · 442

키워드가 29자 이상이면 생성 전에 본문의 키워드를 다듬는다. 썸네일만 줄여 쓰지 않는다.

아이콘을 바꾸는 경우

기본 notebook은 모든 회고에 쓸 수 있다. 글의 중심이 뚜렷할 때만 나침반, 공구, 책처럼 한눈에 알아보는 사물 하나로 바꾼다. 이미 있는 발표 아이콘을 그대로 가져오거나 결과 수치, 로고, 복잡한 흐름도를 그리지 않는다.

  • 16줄, 각 줄 16글자. #는 채움, .은 비움. 여백 행과 열도 생략하지 않는다.
  • 8행과 8열 이상을 차지하고, 주요 윤곽은 두 칸 두께 또는 면으로 그린다.
  • 한 칸마다 <rect x="800 + 16c" y="257 + 16r" width="16" height="16"/>. g#icon 안에 넣으며 중복 칸을 만들지 않는다.
  • 폭 360px의 카드와 1200 × 630 공유 이미지에서 실루엣과 키워드가 선명해야 한다.





  
04생성

  
활동 폴더에 본문을 먼저 쓰고 frontmatter에 thumbnail: img/thumbnail.svg를 지정한다. 기본 notebook은 다음 명령으로 바로 생성한다. 기존 썸네일은 다시 쓴다.

  
node template/retrospective-thumbnail/build.mjs cohort-01/activities/session-02-retrospective

  
직접 그린 아이콘은 16줄의 격자 문자열만 담은 텍스트 파일로 전달한다. 이 파일은 제작용이며 게시물 폴더에 둘 필요가 없다.

  
node template/retrospective-thumbnail/build.mjs cohort-01/activities/cohort-retrospective /tmp/retrospective-icon.txt

  
기수 전체의 회고에는 session을 생략한다. prompt.md는 자료를 읽고 아이콘을 정하는 작업까지 맡길 때 사용한다.





  
05검증

  
node template/retrospective-thumbnail/validate.mjs cohort-01/activities/session-02-retrospective/img/thumbnail.svg

  
    
    
  • 아이보리 바탕, 점 격자, 점선 프레임, 문자 배치가 템플릿과 완전히 같다.
    • 
    
  • 문자는 상단, 키워드 세 줄, 하단의 다섯 줄이다. RECAP은 하단에만 표시한다.
    • 
    
  • 기수, 선택 세션 번호, 키워드가 폴더와 index.md의 값과 맞는다.
    • 
    
  • 아이콘은 격자 안의 중복 없는 rect로만 구성하고 8행 × 8열 이상을 차지한다.
    • 
    
  • 30 KB 이하의 SVG 하나이며 외부 리소스가 없다.
    • 
    
  • 실제 활동 목록의 카드 크기에서 확인하고, 관련 세션이 없는 회고도 확인한다.
    • 
  

  
생성기는 저장 전 같은 규칙으로 검증한다. 검증 스크립트는 직접 작성하거나 수정한 SVG도 검사한다. 페이지 렌더링을 위한 임시 회고를 작성했다면 확인 후 게시물과 임시 자산을 제거한다.
