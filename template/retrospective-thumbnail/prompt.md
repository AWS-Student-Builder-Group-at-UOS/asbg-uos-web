# 회고 썸네일 생성 프롬프트

아래 전체를 복사해 AI에게 전달한다. 입력의 활동 폴더와 근거 자료만 고쳐 쓴다. 기수마다 운영 방식이 다르므로 과제나 세션이 반드시 있다고 가정하지 않는다.

---

## 입력

- 디자인 가이드: `template/retrospective-thumbnail/design-guide.html`
- 회고 폴더: `cohort-01/activities/session-02-retrospective`
- 회고 본문: 위 폴더의 `index.md`와 영어 본문이 있으면 `index.en.md`
- 근거 자료: 본문에서 연결한 활동 자료, 결과물, GitHub 저장소 또는 PR

## 작업

ASBG UOS 회고의 SVG 썸네일 한 장을 만든다. 먼저 본문과 연결된 근거 자료를 읽고 이 회고가 다루는 활동과 배운 점을 파악한다. 과제 제출 수나 성과를 추측해서 본문에 추가하지 않는다. 이 작업의 산출물은 썸네일이다.

가이드를 HTML 원문으로 읽는다. `<script id="template">`가 고정 레이아웃이고, `<script id="digits">`에 세션 번호 숫자, `<script id="glyphs">`에 기본 notebook 격자가 있다. 고정 요소는 02절, 바뀌는 요소와 아이콘 규칙은 03절, 생성 명령은 04절, 검증 항목은 05절, 템플릿은 06절이다.

회고는 **발표와 같은 점 격자, 왼쪽 키워드 세 줄과 세션 번호, 오른쪽 파란 패널과 흰 픽셀 아이콘**으로 만든다. 위치, 크기, 글꼴은 발표와 같고, 회고에는 연한 파랑 바탕과 검정 글자, 파란 강조색을 쓴다. 발표의 점선 프레임 자리를 파란색으로 채운 패널이 회고의 표시다. 유형은 하단의 작은 RECAP 레이블로 구분한다. 별도의 띠, 괘선이나 큰 유형 제목을 추가하지 않는다.

## 절차

1. `index.md`의 `type`이 `retrospective`인지 확인한다. 기수는 `cohort-NN`에서, 관련 세션이 있으면 `session`에서 읽는다. 세션이 없는 회고에 번호를 임의로 붙이지 않는다.
2. `keywords` 세 개를 확인한다. 원래 순서대로 대문자로 쓰며, 영어·숫자·ASCII 문장부호만 사용한다. 각 키워드는 1~28자여야 한다. 범위를 벗어나면 생성 전에 메타데이터를 함께 다듬고 본문과 썸네일을 일치시킨다.
3. 기본 notebook 아이콘을 우선 사용한다. 아래 "아이콘을 바꿀 때"에 해당할 때만 새 16 × 16 격자를 그리고, `.`과 `#`만 있는 16줄로 임시 텍스트 파일에 저장한다.
4. frontmatter에 `thumbnail: img/thumbnail.svg`를 지정한다. 저장소 루트에서 아래 명령을 실행한다. 기본 아이콘이면 두 번째 인자를 생략한다. 기수, 키워드, 세션 번호와 레이블은 스크립트가 폴더 이름과 `index.md`에서 채우고 05절 검증까지 한다.

   ```bash
   node template/retrospective-thumbnail/build.mjs <회고 폴더> [아이콘 격자.txt]
   ```

5. 저장소를 실행할 수 없는 환경에서는 가이드 06절 템플릿을 그대로 복사해 다섯 자리만 채운다.
   - `{{COHORT}}`: 두 자리 기수 번호. 상단의 `ASBG UOS · COHORT NN`에 들어간다.
   - `{{KEYWORDS}}`: x 84의 text 세 줄. 가장 긴 키워드가 18자 이하면 크기 56 / y 318·392·466, 23자 이하면 44 / y 332·392·452, 28자 이하면 36 / y 342·392·442.
   - `{{ICON}}`: 채워진 칸마다 `<rect x="800 + 16c" y="257 + 16r" width="16" height="16"/>`.
   - `{{DIGITS}}`: 세션이 있으면 두 자리 세션 번호의 k번째 숫자(0 또는 1)에서 채워진 칸마다 `<rect x="84 + 84k + 12c" y="570 + 12r" width="12" height="12"/>`. 숫자 모양은 `<script id="digits">`를 그대로 쓴다. 세션이 없으면 비운다.
   - `{{LABEL}}`: 세션이 있으면 `<text x="268" y="626">SESSION</text>`과 `<text x="268" y="666">RECAP</text>` 두 줄, 없으면 `<text x="84" y="666">RECAP</text>` 한 줄.
6. `node template/retrospective-thumbnail/validate.mjs <회고 폴더>/img/thumbnail.svg`를 실행한다. 폭 360px의 카드와 1200 × 630 공유 이미지에서 렌더링을 확인한다. 발표와 구도가 맞고, 연한 파랑 바탕의 글자와 세션 번호, 파란 패널 위의 흰 아이콘이 선명해야 한다. 세션이 없는 글에 가상 번호가 생기지 않는지도 확인한다.
7. 임시 격자·렌더링 파일과 검토용 게시물이 있으면 확인 후 제거한다. 실제 게시할 자료만 남긴다.

## 아이콘을 바꿀 때

- notebook은 모든 회고에 쓸 수 있는 기본값이다. 회고의 중심이 사물 하나로 또렷하게 드러날 때만 바꾼다. 먼저 이 회고가 남기려는 말을 한 문장으로 적고, 그 문장을 나침반, 공구, 책처럼 한눈에 이름을 댈 수 있는 사물 하나로 바꾼다.
- 같은 세션의 발표 아이콘을 그대로 가져오지 않는다. 결과 수치, 로고, 노드와 선으로 된 구성도, 화살표 흐름, UI 기호로 읽히는 모양은 그리지 않는다.
- 그리는 규칙은 가이드 03절과 발표 썸네일 가이드 6.3을 따른다. 면으로 채운 실루엣이 기본이고, 윤곽선은 두 칸 두께, 사물을 알려 주는 특징은 1 ~ 3개만 빈칸으로 뚫는다. 긴 쪽이 12 ~ 14칸을 차지하게 가운데에 놓고, 대칭인 사물은 칸 하나까지 대칭으로 그린다. 사선은 45° 계단으로 잇고, 본체에서 떨어진 점을 흩뿌리지 않는다.
- 활동 카드 크기(폭 약 360px)와 그 절반 크기로 렌더링해 같은 세션의 발표 썸네일과 나란히 놓고 본다. 파란 패널 위의 흰 실루엣만으로 사물이 읽히고, 크기와 무게가 발표 아이콘과 비슷해야 한다.

## 규칙

- 색은 바탕 `#F2FAFF`, 점 격자 `#42B4FF`, 글자 `#0B0F17`, 강조 `#1160D8`, 아이콘 `#FFFFFF`만 쓴다. 상단 문자, 세션 번호, 패널은 `#1160D8`이고 아이콘은 패널 위의 `#FFFFFF` 단색이다. 연한 파랑은 사이트의 `--surface-2`와 같은 값이며 다크 모드에서도 유지한다.
- 루트 비율은 1200 × 750. 배경의 점 격자와 강조 점 46개, 파란 패널, 아이콘 원점, 세션 번호와 문자 위치를 고정한다.
- 문자는 상단, 키워드 세 줄, 레이블뿐이다. 한글, 제목, 작성자, 성과 수치를 추가하지 않는다.
- 세션 번호는 가이드의 숫자 모양을 그대로 쓰고 글자로 쓰지 않는다.
- 키워드의 `&`, `<`, `>`는 SVG 엔티티로 변환한다.
- 외부 글꼴, 이미지, 필터, 그라디언트, 스크립트, 로고를 넣지 않는다.
- 개별 글을 위해 회고 템플릿의 레이아웃을 바꾸지 않는다.

## 출력

- 회고 폴더의 `img/thumbnail.svg` 하나. 파일에는 SVG 코드만 넣는다.
- 사용한 아이콘, 세션 연결 여부, 검증 결과를 짧게 보고한다. 아이콘을 새로 그렸다면 사물 이름과 격자 16줄을 함께 남긴다.
