# 회고 썸네일 생성 프롬프트

아래 전체를 복사해 AI에게 전달한다. 입력의 활동 폴더와 근거 자료만 고쳐 쓴다. 기수마다 운영 방식이 다르므로 과제나 세션이 반드시 있다고 가정하지 않는다.

---

## 입력

- 디자인 가이드: `template/retrospective-thumbnail/design-guide.html`
- 회고 폴더: `cohort-01/activities/session-02-retrospective`
- 회고 본문: 위 폴더의 `index.md`와 영어 본문이 있으면 `index.en.md`
- 근거 자료: 본문에서 연결한 활동 자료, 결과물, GitHub 저장소 또는 PR

## 작업

ASBG UOS 회고의 SVG 썸네일 한 장을 만든다. 먼저 본문과 연결된 근거 자료를 읽고 이 회고가 다루는 활동과 배운 점을 파악한다. 과제 제출 수나 성과를 추측해서 본문에 추가하지 않는다. 이 작업의 산출물은 썸네일이다.

가이드를 HTML 원문으로 읽는다. `<script id="template">`가 고정 레이아웃이고 `<script id="glyphs">`에 기본 notebook 격자가 있다. 회고는 **흰 종이, 왼쪽의 파란 제본 띠, 큰 RECAP 표기, 가로 괘선 위의 키워드 세 줄**로 만든다. 어두운 점 격자 위에 왼쪽 키워드와 오른쪽 아이콘 프레임을 놓는 발표 구성을 사용하지 않는다. 모든 회고는 이 기록지 구성을 유지한다.

## 절차

1. `index.md`의 `type`이 `retrospective`인지 확인한다. 기수는 `cohort-NN`에서, 관련 세션이 있으면 `session`에서 읽는다. 세션이 없는 회고에 번호를 임의로 붙이지 않는다.
2. `keywords` 세 개를 확인한다. 원래 순서대로 대문자로 쓰며, 영어·숫자·ASCII 문장부호만 사용한다. 각 키워드는 1~28자여야 한다. 범위를 벗어나면 생성 전에 메타데이터를 함께 다듬고 본문과 썸네일을 일치시킨다.
3. 기본 notebook 아이콘을 우선 사용한다. 다른 사물이 회고의 핵심을 더 잘 나타낼 때만 가이드 03절에 따라 새 16 × 16 격자를 그린다. 아이콘은 파란 제본 띠 위의 작은 흰 픽셀 기호이므로 실루엣이 단순해야 한다. 격자는 `.`과 `#`만 있는 16줄로 임시 텍스트 파일에 저장한다.
4. frontmatter에 `thumbnail: img/thumbnail.svg`를 지정한다. 저장소 루트에서 아래 명령을 실행한다. 기본 아이콘이면 두 번째 인자를 생략한다.

   ```bash
   node template/retrospective-thumbnail/build.mjs <회고 폴더> [아이콘 격자.txt]
   ```

5. 저장소를 실행할 수 없는 환경에서는 HTML의 템플릿을 그대로 복사해 네 자리만 채운다.
   - `{{COHORT}}`: 두 자리 기수 번호. 하단에 `COHORT NN`으로 표시된다.
   - `{{CONTEXT}}`: 세션이 있으면 ` · SESSION NN`, 없으면 빈 문자열. RECAP 유형 표기는 항상 유지한다.
   - `{{KEYWORDS}}`: x 320의 text 세 줄. 가장 긴 키워드가 18자 이하면 크기 64 / y 360·460·560, 23자 이하면 52 / y 356·456·556, 28자 이하면 44 / y 353·453·553.
   - `{{ICON}}`: 채워진 칸마다 `<rect x="38 + 8c" y="64 + 8r" width="8" height="8"/>`.
6. `node template/retrospective-thumbnail/validate.mjs <회고 폴더>/img/thumbnail.svg`를 실행한다. 폭 360px의 카드와 1200 × 630 공유 이미지에서 렌더링을 확인한다. 흰 종이와 파란 띠, RECAP 표기가 잘 보이고 키워드가 괘선 안에 들어가야 한다. 세션이 없는 글에 가상 번호가 생기지 않는지도 확인한다.
7. 임시 격자·렌더링 파일과 검토용 게시물이 있으면 확인 후 제거한다. 실제 게시할 자료만 남긴다.

## 규칙

- 색은 `#0B0F17`, `#1160D8`, `#42B4FF`, `#FFFFFF`만 쓴다. 검정은 글자와 괘선, 파랑은 제본 띠와 항목 표시, 하늘색은 픽셀 장식, 흰색은 종이와 띠 위의 아이콘이다.
- 루트 비율은 1200 × 750. 종이, 제본 띠, 괘선, RECAP 표기와 문자 위치는 고정한다. 다크 모드에서도 흰 종이를 유지한다.
- 문자는 ASBG UOS, RECAP, 키워드 세 줄, 하단의 여섯 줄이다. 한글, 제목, 작성자, 성과 수치를 추가하지 않는다.
- 키워드의 `&`, `<`, `>`는 SVG 엔티티로 변환한다.
- 외부 글꼴, 이미지, 필터, 그라디언트, 스크립트, 로고를 넣지 않는다.
- 개별 글을 위해 회고 템플릿의 레이아웃을 바꾸지 않는다.

## 출력

- 회고 폴더의 `img/thumbnail.svg` 하나. 파일에는 SVG 코드만 넣는다.
- 사용한 아이콘, 세션 연결 여부, 검증 결과를 짧게 보고한다. 아이콘을 새로 그렸다면 사물 이름과 격자 16줄을 함께 남긴다.
