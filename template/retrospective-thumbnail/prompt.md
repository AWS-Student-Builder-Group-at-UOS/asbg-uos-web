# 활동 회고 썸네일 생성 프롬프트

아래 전체를 복사해 AI에게 전달한다. 맨 위 입력의 활동 폴더와 근거 자료만 고쳐 쓴다. 기수마다 운영 방식이 다르므로 과제나 세션이 반드시 있다고 가정하지 않는다.

---

## 입력

- 디자인 가이드: `template/retrospective-thumbnail/design-guide.html`
- 회고 폴더: `cohort-01/activities/session-02-retrospective`
- 회고 본문: 위 폴더의 `index.md`와 영어 본문이 있으면 `index.en.md`
- 근거 자료: 본문에서 연결한 활동 자료, 결과물, GitHub 저장소 또는 PR

## 작업

ASBG UOS 활동 회고의 SVG 썸네일 한 장을 만든다. 먼저 본문과 연결된 근거 자료를 읽고 이 회고가 다루는 활동과 배운 점을 파악한다. 과제 제출 수나 성과를 추측해서 본문에 추가하지 않는다. 이 작업의 산출물은 썸네일이다.

가이드를 HTML 원문으로 읽는다. `<script id="template">`가 변경 불가한 레이아웃이고 `<script id="glyphs">`에 기본 notebook 격자가 있다. 발표 썸네일의 점선 프레임 대신 회고 전용 실선 기록지 프레임을 사용한다. 모든 회고 썸네일은 같은 배경, 프레임, 문자 배치와 RETROSPECTIVE 표기를 유지한다.

## 절차

1. `index.md`의 `type`이 `retrospective`인지 확인한다. 기수는 `cohort-NN`에서, 세션이 있으면 `session`에서 읽는다. 세션이 없는 회고에 번호를 임의로 붙이지 않는다.
2. `keywords` 세 개를 확인한다. 썸네일에는 원래 순서 그대로 대문자로 쓰며, 영어·숫자·ASCII 문장부호만 쓴다. 각 키워드는 1~28자여야 한다. 범위를 벗어나면 생성 전에 메타데이터를 함께 다듬고 본문과 썸네일을 일치시킨다.
3. 기본 notebook 아이콘을 우선 사용한다. 다른 사물이 회고의 핵심을 더 잘 나타낼 때만 가이드 03절에 따라 새 16 × 16 격자를 그린다. 카드 크기에서 한 단어로 이름을 댈 수 있는 사물 하나여야 한다. 격자는 `.`과 `#`만 있는 16줄로 임시 텍스트 파일에 저장한다.
4. frontmatter에 `thumbnail: img/thumbnail.svg`를 지정한다. 저장소 루트에서 아래 생성 명령을 실행한다. 기본 아이콘이면 두 번째 인자를 생략한다.

   ```bash
   node template/retrospective-thumbnail/build.mjs <회고 폴더> [아이콘 격자.txt]
   ```

5. 저장소를 실행할 수 없는 환경에서는 HTML의 템플릿을 그대로 복사해 네 자리만 채운다.
   - `{{COHORT}}`: 두 자리 기수 번호.
   - `{{CONTEXT}}`: 세션이 있으면 ` · SESSION NN`, 없으면 빈 문자열. 하단은 `RETROSPECTIVE` 또는 `RETROSPECTIVE · SESSION NN`이 된다.
   - `{{KEYWORDS}}`: x 84의 text 세 줄. 가장 긴 키워드가 18자 이하면 크기 56 / y 318·392·466, 23자 이하면 44 / y 332·392·452, 28자 이하면 36 / y 342·392·442.
   - `{{ICON}}`: 채워진 칸마다 `<rect x="800 + 16c" y="257 + 16r" width="16" height="16"/>`.
6. `node template/retrospective-thumbnail/validate.mjs <회고 폴더>/img/thumbnail.svg`를 실행한다. 카드 폭 약 360px와 공유 이미지 1200 × 630에서 렌더링을 확인한다. 해당 글에 세션이 없으면 하단에 가상 번호가 생기지 않는지도 확인한다.
7. 새 아이콘을 만들었다면 임시 격자 파일과 렌더링용 파일을 지운다. 실제로 게시할 본문이 없는 상태에서 검토했다면 임시 회고 게시물도 지운다.

## 규칙

- 색은 `#0B0F17`, `#42B4FF`, `#FFFFFF`만 쓴다. 아이콘은 하늘색 단색이다.
- 루트 SVG의 비율은 1200 × 750. 배경, 프레임, 아이콘 원점과 문자 위치는 바꾸지 않는다.
- 문자 영역은 상단, 키워드 세 줄, 하단의 다섯 줄만 쓴다. 한글, 제목, 작성자, 성과 수치를 추가하지 않는다.
- 키워드의 `&`, `<`, `>`는 SVG 엔티티로 변환한다.
- 외부 글꼴, 이미지, 필터, 그라디언트, 스크립트, 로고를 넣지 않는다.
- 회고 전용 템플릿을 수정해 개별 글의 레이아웃을 만들지 않는다.

## 출력

- 회고 폴더의 `img/thumbnail.svg` 하나. 파일에는 SVG 코드만 넣는다.
- 사용한 아이콘, 세션 연결 여부, 검증 결과를 짧게 보고한다. 아이콘을 새로 그렸다면 사물 이름과 격자 16줄을 함께 남긴다.
